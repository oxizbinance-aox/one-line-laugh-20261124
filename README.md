# The One-Line Laugh

One funny line — a single sentence of at most 200 characters — for the
[make.fun bounty "The One-Line Laugh"](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f).

> I watered my plants on a strict schedule for a month, and the only one that thrived was the plastic one I forgot to water.

`main.ts` (Node 22) writes that line, deterministically and with no input, to
`/output/entry.txt`.
